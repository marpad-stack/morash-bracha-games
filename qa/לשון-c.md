## שאלות לעורכת הלשון ולכותבת

- [עורכת לשון] «בֵּית הַמִּצְווֹת (זוג 4, בראש הרשימה)» — כתיב מלא במנוקד: הצעה 'בֵּית הַמִּצְוֹת'. הזוג נוסף בסבב ולכן לא שונה. אותו דבר בזוג 'בְּלִוּוּי' (ייתכן לִוּוּי תקין, לאימות).
- [כותבת] «חוקרים את הבית, פותרים חידות ומגלים את הרמזים הסודיים! כל שלב שתעברו יקרב אתכם לפתיחת התיבה ולגילוי הגדול.» — חסר. 'ולגילוי הגדול' של מה? אולי 'ולגילוי הסוד הגדול'. הוספתי ניקוד למשפט כפי שהוא.
- [עורכת לשון] «הַחָכְמָה הֲכִי גְּדוֹלָה בָּעוֹלָם כְּתוּבָה בֵּין דַּפַּי (חידת חומש)» — לפי טבלת ההחלפות 'חכמה' ← 'חוכמה'. זו חידה מאושרת, לא שיניתי. לשנות ל'החוכמה'? (וגם 'משה רבינו' ← 'רבנו' ברמז לחומש.)
- [עורכת לשון] «הכרטיס לאמא / לאמא / שאמא (זוגות 7, 279, 317)» — לפי הכללים 'אמא' ← 'אימא'. 'הכרטיס לאמא' הוא שם חלק ושם מותג באתר. בכוונה 'אמא'?
- [עורכת לשון] «נוגעים בחלק עם המסגרת הזהובה; אזור עם אותו מספר; ארבעה משחקים עם אותם ציורים» — 'עם' תיאורי ← 'שבו/בעל' לפי הכללים. מתאים ללשון הילדים או להחליף?
- [עורכת לשון] «פאזל / פאזל הזזה / פאזל רגיל» — הכללים מציעים 'תצרף'. שם משחק מוכר בממשק, לא הוחלף. להשאיר?
- [עורכת לשון] «חוֹפְשִׁי (ציור חופשי; באיזה צבע… חוֹפְשִׁי) מול בְּחָפְשִׁיּוּת (שהוספתי)» — האקדמיה: חָפְשִׁי. הניקוד הקיים 'חוֹפְשִׁי' לא שונה. איזו צורה מועדפת? אם חוֹפְשִׁי, צריך להתאים את 'בְּחוֹפְשִׁיּוּת' שהוספתי בזוג המשחק.
- [עורכת לשון] «כּוּלָּם / כּוּלָּן / כּוּלָּם (זוגות 165, 176, 267)» — הניקוד המלא 'כֻּלָּם' לפי האקדמיה. לא שיניתי, לאישור.
- [עורכת לשון] «סִיוּוּג / תְּסַוְּוגוּ (זוגות 264, 267, 277)» — ניקוד לא ברור לשורש סו"ג (סִוּוּג? סִוְּגוּ?). ספק, לא שונה.
- [עורכת לשון] «עֵדוּיוֹת (זוגות 242, 251, 260)» — עֵדֻיּוֹת? ספק בניקוד הרבים. לא שונה. נִינוֹחַ (217) ובְּלִוּוּי: אותה שאלה.
- [כותבת] «זוגות ניקוד ישנים מול הטקסט בקוד: 'תפסו את הכוכבים! נוגעים בכוכב…' מול 'געו בכוכב כדי לתפוס אותו.'; 'מסדרים את המספרים לפי הסדר משמאל לימין' מול 'מימין לשמאל, מהקטן לגדול'; 'הופכים שני קלפים…' מול 'הופכים קלפים ומחפשים זוגות תואמים!…'» — הניסוחים בזוגות (186–190) אינם בשימוש בקוד. כיוון הסידור שונה (משמאל לימין / מימין לשמאל). אילו ניסוחים נשארים? כשייבחר ניסוח יש לעדכן את הזוג.
- [כותבת] «'געו בכוכב' (אתגר 1)» — 'גְּעוּ' תקין אך נדיר ולא כמו שאר ההוראות ('נוגעים'). בכוונה?
- [עורכת לשון] «אָ ניקוד (כפתור הבורר)» — המילה 'ניקוד' נשארת ללא ניקוד כשהבורר דלוק (נחסם בקוד, עקבי בשאר החלקים). מקווה שהבנתי נכון שזה מכוון.
- [עורכת לשון] «חלק 'בית המצוות': 'ניקוד אותיות: פעיל' (aria/תווית ישנה)» — תווית שנדרסת ל'אָ ניקוד'; אין שינוי נדרש, לידיעה.
- [מרפד] «קוד review/גיבוי-ענן בקובץ (שורות 440 ואילך, כולל 'דוח תיקונים' ו'עריכת הערה')» — בניגוד להחלטה 1 (מוסר מהפרודקשן)? לא נגעתי לפי ההנחיה. מלל המסך הזה כתוב בלשון נקבה ('השאירי', 'נסי'). לבדוק מי הקהל.
- [עורכת לשון] «'מצאת את כל הזוגות!' / 'התלבשת לבד!' / 'חיכית' (מקום: חלק א/ב, זוגות בשימוש משותף)» — פנייה ביחיד מול 'מצאו / בחרו' ברבים באותו מסך. אחידות פנייה? לא שונה.
- [עורכת לשון] «עוד ... אותיות לפתיחת התיבה (toast)» — בלי נקודה בסוף, כמו שאר ההודעות הקצרות (toast). להוסיף נקודה?
