# צוות הבדיקה של הבאת ברכה — איך מפעילים

הכול נמצא בתיקיית `.claude/` (סוכנים, סקיל, צ'קליסטים, סקריפטים) ו-`qa/` (תוצרים). אותם קבצים עובדים מכל כלי.

## 1. בצ'אט של Claude (בלי התקנה)
מעלים את הריפו (או שקלוד מוריד אותו מ-GitHub), אומרים "תריץ את bracha-qa" — קלוד מריץ את הסקריפטים בסנדבוקס שלו ומחזיר `qa/דוח-בדיקות.html`. מגבלה: אין גישה לאתר החי ול-Google Fonts משם.

## 2. Claude Code במחשב (הבית הקבוע) — פעם אחת, צעד-צעד
1. לפתוח טרמינל בתיקיית הריפו (Node ו-Python כבר מותקנים אצלך).
2. `npm i` — מתקין playwright ו-axe-core. ואז `npx playwright install chromium` (או לדלג ולהשתמש ב-Edge: לפני כל הרצה `set BROWSER_CHANNEL=msedge` ב-Windows).
3. `npm i -g @anthropic-ai/claude-code` ואז `claude` — מתחברים עם חשבון ה-Claude (כלול במנוי Pro/Max; המכסה משותפת עם הצ'אט).
4. בטרמינל שני: `npm run serve` (השרת המקומי).
5. ב-Claude Code: `/qa` — מריץ את כל הסוכנים במקביל. `/qa-part ז` — חלק אחד.
6. הדוח: `qa/דוח-בדיקות.html` (לפתוח בדפדפן), הטבלה: `qa/טבלת-הערות.md`.

## 3. בלי טרמינל — Claude Desktop / Cursor
אותה תיקייה. ב-Cursor: הסוכן קורא `AGENTS.md` ו-`CLAUDE.md`; מריצים את הסקריפטים מה-terminal המובנה או מבקשים מהסוכן. Claude Code רץ גם בתוך Cursor (תוסף).

## 4. קודקס (ChatGPT)
קורא `AGENTS.md`. מתאים כחוות דעת שנייה על תוכן: לבקש "הרץ את checklist-content.md על חלק ז וכתוב qa/out/qa-content-g-codex.json בפורמט האחיד". לא לתת לו לערוך קבצים במקביל לקלוד.

## 5. אוטומטי ב-GitHub (Actions)
`.github/workflows/qa.yml` רץ בכל push על תיקיית המסירה: smoke + axe + inventory + notes + report, ומצרף את הדוח כ-artifact. חינם בריפו ציבורי. אין בו AI ואין מפתחות. להפעיל: לשונית Actions → Enable.

## קלט שרק מרפד יכולה לספק
- `qa/in/` — ייצוא "מסמך גיבוי" מדף בדיקה-סופית (ההערות של הבודקות על חלקים ג–י).
- `landing/` — ייצוא HTML של דף הבאת ברכה מהאתר (אופציונלי, לבדיקת הדף עצמו).
- `LANDING_URL=https://morash.co.il/bracha` — בדיקת הדף החי (מהמחשב).
