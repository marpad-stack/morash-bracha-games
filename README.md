# הבאת ברכה — משחקי שפרה ופועה

גיבוי המקורות, קובצי העבודה והמסירה של עשרת חלקי הפרויקט עבור אתר מורה שמיים.

## נקודת המשך — 16.9.2026

סבב הבדיקה הסתיים ב־4.10.2026. **מסירה-משחקי-הבאת-ברכה/בדיקה-סופית.html** הוא עכשיו דף קישורים פשוט לעשרת המשחקים. הערות הבודקות שמורות ב־`qa/in/` ומרוכזות ב־`qa/טבלת-הערות.md`.

פירוט התיקונים והבדיקות נמצא ב־**מסמכים/סיכום-בדיקה-סופית.html** ובדוחות JSON הסמוכים אליו. לפני הפרסום נשארו הגהת הספר והניקוד ומעבר במכשירי טלפון פיזיים. הגרסה טרם פורסמה באתר.

התיקונים נבנים מתוך `upgraded/dev/review.py`, `review.js` ו־`review.css`; דף הקישורים נוצר באמצעות `review-package.py` כחלק מהאריזה. תהליך הבנייה אינו מזריק שכבת סקירה, גיבוי טיוטות או סקריפט חיצוני למשחקים. בדיקות הדפדפן נמצאות ב־`.claude/skills/bracha-qa/scripts/` ומשתמשות ב־Playwright מול שרת בפורט 8765.

## מבנה התיקייה

- **מסירה-משחקי-הבאת-ברכה/** — כל קובצי המסירה המסודרים. מתחילים בקובץ **התחילו-כאן.html**.
- **מסירה-משחקי-הבאת-ברכה/משחקים/** — המשחקים המוכנים לשילוב באתר.
- **מסירה-משחקי-הבאת-ברכה/מסמכים/** — פירוט השינויים, הוראות חיבור והערות תוכן.
- **מסירה-משחקי-הבאת-ברכה/טקסטים/** — התוכן לפי חלקים והעמודים המקוריים של הספר.
- **מסירה-משחקי-הבאת-ברכה/אריזות/** — ZIP נפרד לכל חלק.
- **מסירה-משחקי-הבאת-ברכה/ערכת-תצוגה-לאתר/** — עשר תמונות שער, PNG ו־WebP, תיאורים, קהלי יעד ונתוני כרטיסים ב־CSV ו־JSON.
- **upgraded/dev/** — תבניות, הרחבות, בדיקות וסקריפטי הבנייה.
- **upgraded/source-review/** — תיעוד תוכן שנשלף מהמקורות לצורך עבודה ובדיקה.
- קובצי HTML, ZIP ו־DOCX שבתיקייה הראשית — המקורות המקוריים של הפרויקט.

## צפייה מקומית

מתוך התיקייה הראשית, עם Python מותקן:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

פותחים את `http://127.0.0.1:8765/` ונכנסים לתיקיית המסירה ולקובץ `התחילו-כאן.html`.

## בנייה ובדיקות

מריצים מתוך התיקייה הראשית, עם Python ו־Node.js מותקנים:

```sh
python upgraded/dev/build.py
node upgraded/dev/check.cjs
node upgraded/dev/collect-data.cjs
python upgraded/dev/package.py
python upgraded/dev/verify-package.py
```

הבנייה משתמשת בספריות הסטנדרטיות בלבד. בדיקת התמונות ב־verify-package.py משתמשת גם ב־Pillow. הקבצים הסופיים הם HTML/JavaScript ואינם דורשים Python או Node.js בשרת האתר.

## תוכן ושמירה

הסיפורים, החידות, הברכות, המשימות והכרטיסים נשמרו מן המקורות. בדיקות הזהות והתייחסות לסתירות במקור נמצאות במסמכי המסירה. הספר המקורי כולל 40 תמונות שבהן מוטמע המלל.

בסבב השדרוג השני נוספו בקרי ניקוד בחלקים א–ח ותצוגת קריאה נוספת לספר. הנוסחים החדשים והתמלול נמצאים גם ב־`טקסטים/נוסחי-קריאה-נוספים.json`. אותיות הניקוד החדש בתעלומה וב־18 הברכות נבדקות אוטומטית מול המקור. תמלול הספר והניקוד החדש מיועדים להגהת עורכת לפני הפרסום.

תמונות השער מבוססות על חפצים ונוף, בלי אנשים, חיות או סמלים פוליטיים ודתיים זרים. מפרט האיורים נשמר ב־`upgraded/dev/assets/art-direction.md` ובמסמכי המסירה. הקבצים המקוריים נשארו ללא שינוי.

התקדמות השחקנים, שרטוטים ופרטים שהוזנו בטפסים נשמרים בדפדפן המקומי ואינם חלק ממאגר זה. הכלי לאמהות מאפשר להוריד גיבוי אישי בנפרד.

הגרסה לבדיקה זמינה דרך GitHub Pages. הערות הבודקות מסבב 4.10.2026 נשמרו במסמך הגיבוי `qa/in/גיבוי-הערות-בדיקה.html`.
